# Portfolio outcomes

- [x] The portfolio presents CV-grounded education, internships, projects, achievements, skills, contact details and social links.
- [x] The portfolio is responsive and usable on phone, tablet and desktop widths.
- [x] The portfolio includes an accessible mobile navigation, keyboard-friendly links, skip link, semantic sections and reduced-motion support.
- [x] The portfolio provides the supplied CV as a downloadable/viewable PDF asset.
- [x] The portfolio does not pretend that a contact form sends messages; it uses direct email, phone, LinkedIn and GitHub actions.
- [x] The portfolio includes a route manifest for the single-page route.
